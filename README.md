# Note Checker Piano

A full 88-key piano for checking the notes of a song. Tap a key to hear it and see its name, frequency and MIDI number. Hold two or more keys to see the interval or chord name. Every note you tap is listed so you can write the song down.

Works offline once it has been opened.

## Install it as an app

- **iPhone:** open the site in Safari, tap **Share**, then **Add to Home Screen**.
- **Mac:** open the site in Safari, choose **File > Add to Dock**.

## Tips

- No sound on iPhone? Turn off Silent mode.
- In Settings you can name middle C as C3 to match Logic Pro's default, and fine-tune A4 for recordings that are not at 440 Hz.
